# homebrew-tap

Personal Homebrew tap for macOS.

## Setup

### Add tap repository

```sh
brew tap tomokio/tap
brew trust tomokio/tap
```

## Available Casks

- melissa

## Install casks

```sh
brew install --cask tomokio/tap/<cask-name>
```

## Uninstall casks

```sh
brew uninstall --zap --cask tomokio/tap/<cask-name>
```
